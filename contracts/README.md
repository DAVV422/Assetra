# Assetra Contracts

Contratos inteligentes Soroban para registrar y administrar activos RWA permissioned.

## Alcance del MVP

- RwaRegistry para datos del activo y documentos verificables.
- PermissionedRwaToken para balances y transferencias restringidas.
- Roles de administrador, emisor y encargado de autorizacion.
- Whitelist de participantes.
- Mint, burn, pause, unpause y freeze.
- Transferencia permitida y transferencia bloqueada.
- Pruebas unitarias y despliegue en Stellar Testnet.

## Integracion requerida

La persona responsable publicara el ABI, IDs de contratos, eventos, errores y ejemplos de invocacion. El backend consumira esa interfaz sin que el frontend dependa directamente de Soroban.
